# 📚 Library Fine System - C# WinForms Project

> A smart desktop application to manage library overdue fines automatically.

### 🚀 Features
- ✅ Auto Overdue Calculation: Automatically calculates days overdue
- 💰 Smart Fine Logic: $0.50/day for first 14 days, $1.50/day after 14 days
- ⚠️ Status System: Good Standing / Warning / Auto Suspended
- 🛡️ Input Validation: Prevents all invalid entries

### 💻 Tech Stack
- C# .NET Framework
- Windows Forms (WinForms)
- Visual Studio 2022
